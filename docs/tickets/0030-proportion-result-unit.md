# 0030 Unit chosen for a proportion answer

Status: closed (the reference app)
Milestone: v1
Area: units

`5 km is to 500m as 5 cm is to what` shows `5 mm` in the reference. The engine answers `0.005 m`, the same quantity (5 mm) in a unit that fell out of cancellation. The reference picks a nicer unit; the rule is not documented. Needs a unit-selection rule (ticket 0018 is related).

Settled by the reference app: `5 km is to 500m as 5 cm is to what` prints `0.005 m`, as the engine does. The page's `5 mm` is not what this reference app prints.
