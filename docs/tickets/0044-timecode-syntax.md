# 0044 Timecode syntax beyond the basics

Status: open
Milestone: v1
Area: time

Built from a summary of the timecode notes: `01:02:03:04` literals (24 fps unless the line says `at 30 fps`), sums and differences, a length of time added to a timecode, `as frames`, `as timecode`, and frame arithmetic through the `frame` and `fps` units. Not covered by what was available, and not built: how a frame rate is given in the reference app's own syntax, a global `fps` variable, non-integer rates (23.976, 29.97), drop-frame timecode, and 25 fps PAL. Check a real install and the full page before adding any of them.
