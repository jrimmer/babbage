# 0040 What `X invested Y returned` shows

Status: open
Milestone: v1
Area: finance

The reference lists `$500 invested $1,500 returned` as `2x` and `annual return on $1,000 invested $2,500 returned after 7 years` as `13.99%`. The second uses returned / invested (2.5). The first would be 3x by the same rule, or 2x if the multiple means the gain. The engine uses returned / invested for both. Check a real install.
