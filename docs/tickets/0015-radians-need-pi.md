# 0015 Radians and everything that needs pi

Status: open
Milestone: v1 (row 12)
Area: units, trig

Degrees convert to radians by pi/180, which is irrational. Radian units are not in the registry yet. They arrive with the 50-digit approximate path (row 12) and must carry the approximate marker. `rad`, `rad/s` and trig on `degrees` depend on it.
